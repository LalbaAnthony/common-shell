# Configs PowerShell

Useful aliases and functions to boost your productivity in the terminal.

## 🚀 Setup

### Bash

Empty `.bash_aliases` if needed:
```sh
> ~/.bash_aliases
```

Install:
```sh
bash <(curl -fsSL https://raw.githubusercontent.com/LalbaAnthony/antho-common-shell/main/install.sh)
```

Update:
```sh
bash <(curl -fsSL https://raw.githubusercontent.com/LalbaAnthony/antho-common-shell/main/install.sh)
```

Uninstall:
```sh
bash <(curl -fsSL https://raw.githubusercontent.com/LalbaAnthony/antho-common-shell/main/uninstall.sh)
```

### PowerShell

Empty `$PROFILE` if needed:
```ps1
$null > $PROFILE
```

Install:
```sh
irm https://raw.githubusercontent.com/LalbaAnthonyantho-common-shell/main/install.ps1 | iex
```

Update:
```sh
irm https://raw.githubusercontent.com/LalbaAnthonyantho-common-shell/main/install.ps1 | iex
```

Uninstall:
```sh
irm https://raw.githubusercontent.com/LalbaAnthonyantho-common-shell/main/uninstall.ps1 | iex
```
